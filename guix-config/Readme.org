#+startup: overview

Guix manual: https://guix.gnu.org/manual/devel/en/guix.html

=make help= lists the targets. =make= (=sync=) copies =/etc/config.scm= into =config-pc.scm= and the Nix profile into =nix-config/=.

* Guix System (pc)
=config-pc.scm= imports modules under =(nbl ...)= from =modules/nbl/=, so pass =-L modules=. Don't pass the repo root: guix would try to load its loose =.scm= files as modules.
#+begin_src sh
sudo guix system reconfigure -L ~/dotfiles/guix-config/modules /etc/config.scm
#+end_src

* Guix Home (both hosts)
=home.scm= picks the host by =(gethostname)=; any hostname other than =pc= or =thinkpad= is an error.
- Packages: =common-packages=, plus =pc-packages= or =thinkpad-packages=. The pc's system packages stay in =config-pc.scm=, and the thinkpad's root-side tools come from apt.
- Links: every link from =$HOME= into =~/dotfiles= (see =../README.org=, "Symlinks").
- pc only: D-Bus and PipeWire user services. The thinkpad uses Debian's PipeWire; a second one would fight it for the sound card.
#+begin_src sh
make check-guix-home   # build only
make apply-guix-home   # remove old ln -sf links, then guix home reconfigure
#+end_src
=~/.guix-profile= stays empty, for trying packages with =guix install=. =make sync= lists anything left in it.

Run JACK apps (Ardour, SuperCollider) through PipeWire with =pw-jack=, e.g. =pw-jack ardour9=.

* Pinned channels
=channels.scm= follows each channel's HEAD. =channels-lock.scm= records the exact commits, so it plus =home.scm= reproduces an environment.
#+begin_src shell
guix describe -f channels > ~/dotfiles/guix-config/channels-lock.scm   # after a guix pull you want to keep
guix time-machine -C ~/dotfiles/guix-config/channels-lock.scm -- \
     home reconfigure ~/dotfiles/guix-config/home.scm -L ~/dotfiles/guix-config/modules
#+end_src

* ./other/scripts
- =uv-guix-shell.sh= runs =uv= in a container with the usual Linux file system layout (FHS).
- =fix-foreign-binary.sh= fixes a binary that fails because Guix doesn't follow the FHS.
- =repo-risk.sh= lists every git repo under =$HOME= with anything uncommitted, stashed or unpushed.
- =clear-home-links.sh=: =make apply-guix-home= runs it.
- =webcam-stream.sh= streams the webcam, to watch it from the phone over SSH; usage is at its top.

* Nix
For packages Guix doesn't have. On the pc, =config-pc.scm= has =(service nix-service-type)=; the thinkpad has no Nix.
#+begin_src shell
source /run/current-system/profile/etc/profile.d/nix.sh
nix-channel --update
make apply-nix-profile        # installs nix-config/attribute-manifest.nix
#+end_src
