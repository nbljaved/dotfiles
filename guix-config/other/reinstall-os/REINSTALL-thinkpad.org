#+title: Install Debian 13 + Guix on =thinkpad=
#+subtitle: Lenovo ThinkPad T460 — last run 2026-10
#+startup: content
#+options: toc:2 num:t ^:nil
#+property: header-args :eval no

Wipes the whole disk, installs Debian 13 "trixie" with LUKS, then puts Guix on top.
- *Debian owns* everything that runs as root or checks a password: kernel, firmware, X, =i3lock=, NetworkManager, PipeWire, Bluetooth and Tailscale. =unattended-upgrades= patches it.
- *Guix Home owns* the user environment (=home.scm=).

Code blocks are =:eval no=, so copy them on purpose. *DESTRUCTIVE* blocks erase data.

* Open items from the 2026-10 run
- [ ] Tailscale (7.1)
- [ ] Wi-Fi, Bluetooth, sound (=pavucontrol=), suspend and resume
- [ ] Optional: give the volume group's leftover space to root (end of 4.7)

* Decisions
- *Root never runs a store binary.* The Guix daemon is unprivileged and owns =/gnu/store=. As long as root-side programs come from apt, a compromised daemon stays at user level. The one exception is =sudo -i guix pull= (5.3), which is how the daemon gets updated.
- *Hibernation, not Secure Boot.* Debian's kernel disables hibernation under Secure Boot ("lockdown"). Hibernation writes RAM into the encrypted swap, so the keys leave memory and resuming asks for the passphrase again. LUKS is what protects the data.
- *=startx= on tty1*, with no display manager. That means fewer root components, and the login shell already has Guix's environment.
- *No SSH server*, and a new GitHub key for each machine.
- *No Nix.* Debian runs =uv= wheels and vendor binaries natively.
- *Tailscale from its signed apt repo*, so =unattended-upgrades= patches it.
- *No backup drive:* =git push= is the backup, as on the pc.
- *The hostname must be =thinkpad=*, because =home.scm= keys on it.

* Phase 1 — Before the wipe
- =bash ~/dotfiles/guix-config/other/scripts/repo-risk.sh=: every line must say =ok=. To rescue stashes, see =REINSTALL-pc.org= 1.1.
- Note the RAM (=free -h=) for 3.3, and the disk (=lsblk -d -o NAME,SIZE,MODEL=) so you pick the right one.
- Choose a LUKS passphrase and write it on paper.

* Phase 2 — The USB stick (on another machine)
#+begin_src sh
B=https://cdimage.debian.org/debian-cd/current/amd64/iso-cd
curl -L -O "$B/SHA512SUMS" -O "$B/SHA512SUMS.sign"
ISO=$(awk '/ debian-13[.0-9]*-amd64-netinst\.iso$/ {print $2}' SHA512SUMS)
curl -L -O "$B/$ISO"
export GNUPGHOME=$(mktemp -d)
curl -sSL https://www.debian.org/CD/key-DA87E80D6294BE9B.txt | gpg --import
gpg --verify SHA512SUMS.sign SHA512SUMS     # Good signature, DF9B 9C49 EAA9 2984 3258  9D76 DA87 E80D 6294 BE9B
sha512sum --ignore-missing -c SHA512SUMS    # <ISO>: OK
lsblk -o NAME,SIZE,MODEL,TRAN               # the stick has TRAN=usb
#+end_src
*DESTRUCTIVE.* Write to the whole device (=/dev/sdb=), never a partition (=/dev/sdb1=). On a partition, the firmware finds no boot loader and the =F12= entry does nothing.
#+begin_src sh
sudo dd if="$ISO" of=/dev/sdX bs=4M status=progress conv=fsync
lsblk -o NAME,FSTYPE /dev/sdX               # sdX itself says iso9660
#+end_src

* Phase 3 — Install Debian
** 3.1 BIOS (=Enter=, then =F1=)
Set UEFI Only, CSM off and Secure Boot *off*. =F10= saves, and =F12= at power-on picks the stick.

** 3.2 Installer
- Location /other → Asia → India/, locale =en_IN.UTF-8=, keyboard American English.
- Hostname =thinkpad=, with an empty domain.
- Leave the root password empty, so =nabeel= gets =sudo=. The user is =nabeel=.

** 3.3 Partitioning — DESTRUCTIVE
1. Choose /Guided - use entire disk and set up encrypted LVM/ on the internal disk, with all files in one partition.
2. Let the erase finish.
3. When asked how much of the volume group to use, *leave RAM + 2 GB free*: e.g. =230 GB= of 240 with 8 GB of RAM. 4.7 grows swap into that space for hibernation.

** 3.4 Software
Untick the desktop environments and tick only "standard system utilities".

* Phase 4 — Debian base
=/usr/sbin= isn't on a normal user's =PATH=, so =swapon=, =blkid=, =lvs= and similar need =sudo=.
** 4.1 Updates
#+begin_src sh
sudo apt update && sudo apt full-upgrade
sudo apt install intel-microcode firmware-iwlwifi
#+end_src

** 4.2 Firmware
#+begin_src sh
sudo apt install fwupd
sudo fwupdmgr refresh && sudo fwupdmgr update     # on AC power
#+end_src

** 4.3 Automatic security updates
#+begin_src sh
sudo apt install unattended-upgrades apt-listchanges needrestart
sudo dpkg-reconfigure -plow unattended-upgrades   # Yes
#+end_src
It never reboots by itself. =.bashrc= tells you when =/var/run/reboot-required= exists.

** 4.4 Firewall
#+begin_src sh
sudo apt install ufw
sudo ufw default deny incoming && sudo ufw default allow outgoing && sudo ufw enable
#+end_src

** 4.5 Host packages
#+begin_src sh
sudo apt install \
  xserver-xorg-core xserver-xorg-input-libinput xinit xauth x11-xserver-utils \
  i3lock xss-lock dbus-user-session dbus-bin \
  network-manager pipewire-audio bluez udisks2 \
  nscd uidmap gnupg wget xz-utils \
  git curl make age zstd \
  pulseaudio-utils brightnessctl blueman
id                                   # must include video (brightnessctl) and audio
#+end_src
- =i3lock= checks the password through Debian's PAM, which a Guix copy can't do.
- =guix-install.sh= needs =uidmap=, =gnupg=, =wget= and =xz-utils=. Guix programs look up users and hosts through =nscd=.
- =blueman='s applet needs =blueman-mechanism=, a root D-Bus service. Guix Home's =blueman-applet= comes first on =PATH=, so =defcommands.lisp= runs =/usr/bin/blueman-applet= on this machine.

** 4.6 NetworkManager
Remove the install-time connection from =/etc/network/interfaces=, keeping only =source= and =lo=. While it's listed there, NetworkManager leaves the device unmanaged. If you installed over Wi-Fi, its password sits there in plain text.
#+begin_src sh
sudoedit /etc/network/interfaces
sudo reboot
nmcli device wifi connect "<SSID>" --ask
#+end_src

** 4.7 Hibernation
Grow swap to RAM + 2 GB, using the space 3.3 left free:
#+begin_src sh
sudo lvs -o lv_path,lv_size          # the swap volume, e.g. /dev/thinkpad-vg/swap_1
SWAP=/dev/<vg>/<swap lv>
SIZE=$(awk '/MemTotal/ {printf "%dG", int($2/1048576)+2}' /proc/meminfo)
sudo swapoff "$SWAP" && sudo lvextend -L "$SIZE" "$SWAP" && sudo mkswap "$SWAP" && sudo swapon "$SWAP"
cat /etc/initramfs-tools/conf.d/resume; grep swap /etc/fstab
#+end_src
If either file names the swap by =UUID==, replace it with the new one (=sudo blkid "$SWAP"=). A =/dev/mapper/…= path needs no change. Then:
#+begin_src sh
sudo update-initramfs -u -k all
sudo systemctl hibernate             # resuming asks for the LUKS passphrase
#+end_src
To suspend first and hibernate after 15 minutes:
#+begin_src sh
sudo mkdir -p /etc/systemd/sleep.conf.d /etc/systemd/logind.conf.d
printf '[Sleep]\nHibernateDelaySec=15min\n' | sudo tee /etc/systemd/sleep.conf.d/10-delay.conf
printf '[Login]\nHandleLidSwitch=suspend-then-hibernate\n' | sudo tee /etc/systemd/logind.conf.d/10-lid.conf
sudo systemctl restart systemd-logind
#+end_src
Leftover space can go to root: =sudo lvextend -l +100%FREE /dev/<vg>/root && sudo resize2fs /dev/<vg>/root=.

* Phase 5 — Guix
** 5.1 Install
Use a binary tarball built after 2026-07-05; the 1.5.0 release, which =guix-install.sh= fetches by default, has the vulnerable =guix substitute=. The newest CI build is at https://ci.guix.gnu.org/search/latest/archive?query=spec:tarball+status:success+system:x86_64-linux+guix-binary.tar.xz. Keep =system:x86_64-linux= in that link: without it you can get another architecture.
#+begin_src sh
cd /tmp
curl -L -o guix-binary.x86_64-linux.tar.xz '<the link above>'   # the name must contain x86_64-linux
curl -fsSL -o guix-install.sh https://guix.gnu.org/guix-install.sh && chmod +x guix-install.sh
sudo env GUIX_BINARY_FILE_NAME=/tmp/guix-binary.x86_64-linux.tar.xz ./guix-install.sh
#+end_src
- Answers: AppArmor profile *y*; discover substitute servers on the local network *n*; build-farm substitutes *y*; customize the prompt *n*.
- It must say "installing guix-daemon to run as an unprivileged user".
- Log out and back in afterwards.

** 5.2 Check the daemon — STOP if not patched
#+begin_src sh
ps -o user= -C guix-daemon           # guix-daemon
G=/var/guix/profiles/per-user/root/current-guix
grep -c 'define (rename-file\*' "$G/share/guile/site/3.0/guix/scripts/substitute.scm"   # must print 1
guix build hello                     # downloads, builds nothing
#+end_src

** 5.3 Update the daemon
The daemon is root's guix. Update it now, and whenever a Guix advisory lands:
#+begin_src sh
sudo -i guix pull && sudo systemctl restart guix-daemon
#+end_src
Use =sudo -i=, not plain =sudo=. Plain =sudo= keeps your =PATH=, so it would run, and update, your guix instead of root's.

** 7.2 xremap
Don't run it with =sudo=: root must not run a store binary, and Debian's =sudo= drops your =PATH= anyway. Give your user access to the devices instead:

echo 'KERNEL=="uinput", GROUP="input", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/99-uinput.rules
sudo usermod -aG input nabeel
sudo reboot
xremap --watch=device,config ~/dotfiles/guix-config/.config/xremap/xremap.yaml
#+end_src

* Troubleshooting
- *=F12= lists the stick, but nothing boots:* the ISO was written to a partition (Phase 2).
- *Hibernation problems* (4.7):
  - "Not enough swap space": swap is smaller than RAM.
  - A fresh session instead of a resume: =/etc/initramfs-tools/conf.d/resume= names a stale UUID.
  - "Not supported": Secure Boot is on.
- *=guix-install.sh= says "Missing commands: newgidmap":* =sudo apt install uidmap=.
- *The daemon runs as root:* the wrong tarball, or no systemd. Uninstall with =sudo ./guix-install.sh --uninstall= and redo 5.1.
- *A local build fails with =chown= or =Errno 22=:* that's the unprivileged daemon. Wait for a substitute, or use =--without-tests==.
- *Locale warnings:* open a new login shell, so =GUIX_LOCPATH= is set.
- *Missing fonts:* =fc-cache -f=.
- *blueman only half works:* =type -a blueman-applet=. The running applet must be =/usr/bin/blueman-applet=.
- *udiskie only half works:* =udisks2= from apt is what it needs.
- *StumpWM doesn't start, or =apply-guix-home= errors:* =hostname= must print =thinkpad=.
- *No Wi-Fi after 4.6:* =nmcli device= says "unmanaged" while =/etc/network/interfaces= still lists the device.
- *AppArmor blocks builds:* =sudo journalctl -k | grep 'apparmor="DENIED".*guix'=.
