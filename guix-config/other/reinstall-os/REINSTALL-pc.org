#+title: Reinstall Guix System on =pc=
#+subtitle: Lenovo ThinkCentre M70s Gen 6 — last run 2026-10
#+startup: content
#+options: toc:2 num:t ^:nil
#+property: header-args :eval no

Wipes the whole of =/dev/nvme0n1= and installs Guix System from =~/dotfiles=, with an encrypted root. Code blocks are =:eval no=, so copy them on purpose. *DESTRUCTIVE* blocks erase data. Push this file first: you can read it on your phone while the disk is empty.

* Open items from the 2026-10 run
- [ ] Tailscale (3.6)
- [ ] SSH into the pc from another machine (=ssh-keygen -R pc= there first)
- [ ] Containers: =make -C ~/dotfiles/guix-config distrobox=
- [ ] PipeWire from Guix Home: =herd status= lists =pipewire=, =wireplumber= and =pipewire-pulseaudio=; =pactl info= says =PulseAudio (on PipeWire …)=

* Decisions
- *Disk:* p1 is a 512 MiB EFI partition. p2 is LUKS2, holding one ext4 =guix-root= (=/=, =/boot=, =/home=, =/gnu=, =/nix=) and a 32 GiB =/swapfile= for hibernation. The swap file is RAM-sized because elogind refuses to hibernate once used memory passes 98% of free swap. There's no swap partition, because it would sit outside the encryption.
- *One passphrase, typed at GRUB.* GRUB unlocks p2 to read =/boot= and hands the key to the initrd, so you're asked once ("Automatic LUKS Master Key Passing" in the manual; nothing to configure). GRUB asks before it can load a keymap, so it uses a US layout: keep the passphrase plain ASCII.
- *argon2id at 256 MiB.* GRUB redoes the KDF before boot with little memory, and cryptsetup's 1 GiB default can leave the machine unbootable. Needs GRUB 2.14 or newer (=guix show grub-efi=).
- *Unprivileged daemon:* =(privileged? #f)= in =config-pc.scm=. Packages built locally may fail their tests (=chown= returns EINVAL), but substitutes make local builds rare. To go back, delete the line and reconfigure.
- *No backup drive:* =git push= is the backup. Anything uncommitted, unpushed or stashed is lost, and so are browser profiles, app logins and =~/Downloads=.
- *Not protected:* the EFI partition and GRUB are unsigned (there's no Secure Boot), so someone with the machine in hand can still tamper with the boot path.

* Phase 1 — Before the wipe
** 1.1 Push every repo
#+begin_src sh
make -C ~/dotfiles/guix-config sync                 # config-pc.scm from /etc/config.scm; commit it
bash ~/dotfiles/guix-config/scripts/repo-risk.sh    # every line must say ok
#+end_src
To rescue a stash, push it as a branch:
#+begin_src sh
git stash branch rescue/stash-0 'stash@{0}'
git add -A && git commit -m "rescued stash" && git push -u origin rescue/stash-0
#+end_src

** 1.2 Carry the secrets out
Put these on the thinkpad, or on paper. The thinkpad has no SSH server, so pull from it: =scp 'nabeel@pc:~/.age/key*' ~/.age/=.
- =~/.age/key= is the only key to =diary.org.age=, and it can't be replaced. Prove it works on the thinkpad: =age -d ~/diary/diary.org.age | head -1=. A passphrase-wrapped copy (=age -p -o key.age ~/.age/key=) can live in a private repo; it only unwraps at a terminal.
- The Mullvad account number. It /is/ the account.
- Wi-Fi passwords: =sudo grep -h -e '^ssid=' -e '^psk=' /etc/NetworkManager/system-connections/*=

** 1.3 Make sure you can get back in

** 1.4 Write the USB stick
Use a Guix ISO built after 2026-07-05; the 1.5.0 release has the vulnerable =guix substitute=. The newest CI build is at https://ci.guix.gnu.org/search/latest/ISO-9660?query=spec:images+status:success+system:x86_64-linux+image.iso
#+begin_src sh
lsblk -o NAME,SIZE,MODEL,TRAN        # the stick has TRAN=usb, e.g. sdb
#+end_src
*DESTRUCTIVE.* Write to the whole stick (=sdX=, not =sdX1=):
#+begin_src sh
sudo dd if=guix-install.iso of=/dev/sdX bs=4M status=progress conv=fsync
#+end_src

* Phase 2 — Install from the USB
** 2.1 Boot and network
- Plug in Ethernet or USB-tether your phone. Wi-Fi won't work: it needs non-free firmware the installer doesn't have.
- =F12= picks the stick (=F1= is BIOS setup). Choose "Install using the shell based process", which gives a root shell on TTY3.
- ConnMan sets up Ethernet by itself. Check with =ip -br addr= and =ping -c 3 gnu.org=.
  - =NO-CARRIER= in =ip -br link= is the cable. Use one of the router's LAN ports, not WAN.
  - No lease: =herd stop connman; dhcpcd <iface>=.
- Black screen: at GRUB press =e= and add =nomodeset= to the =linux= line.

** 2.2 Check the installer's daemon is patched — STOP if not
#+begin_src sh
G=$(ps -o args= -C guix-daemon | awk 'NR==1{print $1}' | sed 's#/bin/guix-daemon$##')
grep -c 'define (rename-file\*' "$G/share/guile/site/3.0/guix/scripts/substitute.scm"   # must print 1
#+end_src

** 2.3 Partition and encrypt — DESTRUCTIVE
=lsblk= must show =nvme0n1= and the USB stick, and nothing else.
#+begin_src sh
lsblk -o NAME,SIZE,TYPE,FSTYPE,LABEL,MODEL,TRAN
swapoff -a
wipefs -a /dev/nvme0n1p* /dev/nvme0n1
blkdiscard -f /dev/nvme0n1           # TRIM every block, so no old plaintext stays readable
parted -s /dev/nvme0n1 -- mklabel gpt \
  mkpart ESP fat32 1MiB 513MiB set 1 esp on \
  mkpart guix-root 513MiB 100%
mkfs.fat -F32 -n ESP /dev/nvme0n1p1
cryptsetup luksFormat --type luks2 \
  --pbkdf argon2id --pbkdf-memory 262144 --pbkdf-force-iterations 4 \
  --verify-passphrase /dev/nvme0n1p2
cryptsetup open /dev/nvme0n1p2 cryptroot
mkfs.ext4 -L guix-root /dev/mapper/cryptroot
#+end_src

** 2.4 Mount, cow-store, swap file
#+begin_src sh
mount LABEL=guix-root /mnt
mkdir -p /mnt/boot/efi && mount /dev/nvme0n1p1 /mnt/boot/efi
herd start cow-store /mnt
dd if=/dev/zero of=/mnt/swapfile bs=1MiB count=32768 status=progress   # 32 GiB = RAM
chmod 600 /mnt/swapfile && mkswap /mnt/swapfile && swapon /mnt/swapfile
OFF=$(filefrag -e /mnt/swapfile | grep '^ *0:' | cut -d: -f3 | cut -d. -f1 | tr -d ' '); echo "$OFF"
#+end_src

** 2.5 Put the new IDs into config-pc.scm
=config-pc.scm= already sets up the encrypted root. Only the LUKS UUID, the EFI UUID and the swap file's offset change.
#+begin_src sh
mkdir -p /mnt/root && cd /mnt/root
guix shell git -- git clone https://github.com/nbljaved/dotfiles.git
cd dotfiles/guix-config
LUKS=$(cryptsetup luksUUID /dev/nvme0n1p2)
ESP=$(blkid -s UUID -o value /dev/nvme0n1p1)
sed -i -e "s/(uuid \"[0-9a-f-]\{36\}\")/(uuid \"$LUKS\")/" \
       -e "s/(uuid \"[0-9A-F]\{4\}-[0-9A-F]\{4\}\"/(uuid \"$ESP\"/" \
       -e "s/resume_offset=[0-9]*/resume_offset=$OFF/" config-pc.scm
git diff                             # exactly three lines: the two UUIDs and resume_offset
mkdir -p /mnt/etc
cp config-pc.scm /mnt/etc/config.scm
cp signing-key.pub /mnt/etc/         # config.scm refers to ./signing-key.pub
#+end_src

** 2.6 Pull nonguix, then install
The installer's guix has no nonguix, and the config needs it. Don't use =channels-lock.scm= here.
#+begin_src sh
guix archive --authorize < /mnt/root/dotfiles/guix-config/signing-key.pub   # nonguix's substitute key
cat > /tmp/channels.scm <<'EOF'
(cons (channel
       (name 'nonguix)
       (url "https://gitlab.com/nonguix/nonguix")
       (introduction
        (make-channel-introduction
         "897c1a470da759236cc11798f4e0a5f7d4d59fbc"
         (openpgp-fingerprint
          "2A39 3FFF 68F4 EF7A 3D29  12AF 6F51 20A0 22FB B2D5"))))
      %default-channels)
EOF
SUBS="https://ci.guix.gnu.org https://bordeaux.guix.gnu.org https://substitutes.nonguix.org"
guix pull -C /tmp/channels.scm --substitute-urls="$SUBS"
export PATH=/root/.config/guix/current/bin:$PATH; hash -r
cd /mnt/root/dotfiles/guix-config
guix system build -n -L modules config-pc.scm --substitute-urls="$SUBS"   # catches Scheme errors
guix system init -L modules config-pc.scm /mnt --substitute-urls="$SUBS"
grep -nE 'cryptomount|luks_script' /mnt/boot/grub/grub.cfg                # both must be there
reboot                               # pull the stick out at the Lenovo logo
#+end_src
- =init= ends with "bootloader successfully installed". If nonguix has no substitute for the current kernel, the kernel builds here, for about an hour.
- No =cryptomount= line means GRUB can't read =/boot=, and you'll land at a rescue prompt. No =luks_script= means the machine boots but asks for the passphrase twice.

* Troubleshooting
- *GRUB rejects the passphrase or runs out of memory:* boot the USB and run =cryptsetup open /dev/nvme0n1p2 cryptroot= and then =cryptsetup luksConvertKey --pbkdf pbkdf2 /dev/nvme0n1p2=. Then reconfigure.
- *=guix system init= builds the kernel:* either nonguix's key isn't authorized, or =$SUBS= is unset because you're in a new shell.
- *"no file system with label guix-root":* the label is on =/dev/mapper/cryptroot=, not on =p2=. Check with =e2label=.
- *Tests fail with =Errno 22= or chown errors:* a local build on the unprivileged daemon. Use a substitute, or go privileged (see Decisions).
- *Hibernation doesn't resume:* =resume_offset= is stale. Get the new one with =sudo filefrag -e /swapfile=, fix it, and reconfigure.
- *"Not enough suitable swap space for hibernation":* =Active(anon)= in =/proc/meminfo= is over 98% of free swap. Close programs, or grow =/swapfile= and redo the offset.
- *=sudo guix system reconfigure= says =linux: unbound variable=:* that's root's guix, which has no nonguix. Use the command in 3.4.
