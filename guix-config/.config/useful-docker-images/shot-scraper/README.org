* shot-scraper in a container
[[https://github.com/simonw/shot-scraper][shot-scraper]] takes screenshots of web pages with Playwright. =bin/shot-scraper= runs it through Docker or Podman. =.bashrc= puts =bin/= on =PATH=, and Guix Home links =claude-skills/shot-scraper.md= as a Claude Code skill.

#+begin_src shell
make                       # build the image, then check shot-scraper is on PATH
shot-scraper https://example.com -w 1200 -h 800 -o screenshot.png
shot-scraper http://localhost:8000
shot-scraper shots.yml     # several shots from a config file
#+end_src
