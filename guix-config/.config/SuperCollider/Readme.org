Guix Home links both files into =~/.config/SuperCollider/= (=../../home.scm=). The rest of that directory is sessions, autosaves and cache.

| File               | What                                                           |
|--------------------+----------------------------------------------------------------|
| =sc_ide_conf.yaml= | IDE preferences: editor theme and font, shortcuts, post window |
| =sclang_conf.yaml= | interpreter include/exclude paths (Quarks, extensions)         |

scide also writes its recent files (=IDE/recentDocuments=) into =sc_ide_conf.yaml=. Leave those lines out of commits (=git add -p=).

* Run
=pw-jack= points the =libjack= that Guix's =scsynth= links at PipeWire, since no =jackd= runs here.
#+begin_src shell
pw-jack scide                       # Ctrl+B boots the server, Ctrl+Enter evaluates, Ctrl+. stops sound
pw-jack sclang                      # REPL, no IDE
pw-jack scsynth -u 57110            # just the server
pw-jack -p 256 scide                # lower latency: a 256-sample period (default 1024)
QT_QPA_PLATFORMTHEME=gtk3 pw-jack scide   # dark window chrome; the editor theme is under Preferences → Editor
#+end_src
