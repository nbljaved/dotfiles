#+TITLE: StumpWM configuration

One config for two machines. =init.lisp= sets =pc?= from the hostname, and everything machine-specific keys off it.
- *pc:* Guix System. GDM starts the session.
- *thinkpad:* Debian with Guix on top. =startx= on tty1 (=.bash_profile=) reads =xinitrc=.

Guix Home links =~/.config/stumpwm/config= to =init.lisp= on both machines, and =~/.xinitrc= to =xinitrc= on the thinkpad. =init.lisp= loads everything else from =~/dotfiles/stumpwm.d/= (=*config-dir*=). =~/.stumpwm.d/= holds only runtime state (log, history, =winner-layouts/=). Don't put an =init.lisp= there: it would win over =~/.config/stumpwm/config=.

* Layout
| Path                              | What it is                                                           |
|-----------------------------------+----------------------------------------------------------------------|
| =init.lisp=                       | entry point: loads quicklisp if present, slynk, then the files below |
| =modules.lisp=                    | =*module-dir*= and the contrib modules that get loaded               |
| =defcommands.lisp=                | commands, and the =*-start= helpers =startup.lisp= calls             |
| =keybinding.lisp=                 | keys                                                                 |
| =modeline.lisp=                   | mode line                                                            |
| =startup.lisp=                    | runs once at startup: applets, wallpaper, pc-only extras             |
| =load-fonts.lisp=                 | TrueType font (see Quicklisp)                                        |
| =config/=                         | configs for the programs StumpWM starts                              |
| =Xresources=, =Xresources.<host>= | X resources, merged by =xinitrc=                                     |
| =xinitrc=                         | =~/.xinitrc=, thinkpad only                                          |
| =bootstrap-quicklisp.sh=          | rebuilds =~/quicklisp= from upstream                                 |
| =modules/=                        | submodule: stumpwm-contrib                                           |
| =clx-truetype/=                   | submodule: goose121's fork, loaded through quicklisp                 |
| =wallpapers/=                     | =wallpaper= picks one at random                                      |

* =config/=
Not linked into =~/.config=: each program is given its path here, so edit in place and restart the program.
| Program      | Started by                     | Config                         |
|--------------+--------------------------------+--------------------------------|
| =picom=      | =picom-start=                  | =config/picom/picom.conf=      |
| =udiskie=    | =udiskie-start=                | =config/udiskie/udiskie.conf=  |
| =xsettingsd= | =xsettingsd-start=, pc only    | =config/xsettingsd/.xsettingsd= (the pc's HiDPI: =Xft/DPI 147456= is 144 × 1024) |
| =rofi=       | =rofi=, bound to =s-d=         | =config/rofi/config.rasi=      |
| =polybar=    | nothing: =launch-polybar= points at a missing =~/.config/polybar/launch.sh= | =config/polybar/= |

* X resources
Only a session that runs =xrdb= reads them, so only the thinkpad does. GDM never runs it; on the pc, =xsettingsd= does that job.

* thinkpad notes
- =xinitrc= calls Debian's =/usr/bin/i3lock=: the locker must check passwords through Debian's PAM.
- Guix Home comes before =/usr/bin= on =PATH=. So =bluetooth-start= uses =*blueman-applet*=, which is =/usr/bin/blueman-applet= off the pc: the applet needs Debian's root D-Bus service. =type -a <command>= shows which copy wins.

* Quicklisp
Only for =clx-truetype= (the antialiased font in =load-fonts.lisp=) and the =alert-me= module. StumpWM starts without it, using X core fonts. To rebuild it (this verifies the installer's signature and links =clx-truetype=):
#+begin_src shell
bash ~/dotfiles/stumpwm.d/bootstrap-quicklisp.sh
#+end_src
=load-fonts.lisp= reads DejaVu Sans Mono from =/run/current-system/profile/share/fonts/= on the pc and =~/.guix-home/profile/share/fonts/= on the thinkpad, and caches the font list in =~/.fonts/font-cache.sexp=.
