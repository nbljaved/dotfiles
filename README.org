The archived repos =nbljaved/{emacs,shell,stumpwm,guix}-config= live on here: =git log -- emacs.d/=.

* Install
#+begin_src shell
git clone --recurse-submodules git@github.com:nbljaved/dotfiles.git ~/dotfiles
make -C ~/dotfiles/guix-config apply-guix-home
#+end_src

* Symlinks
Guix Home makes every link from =$HOME= into this repo, on both machines; the list is in =guix-config/home.scm=. The links point at the files here, not at copies in the store, so edits take effect at once. Re-run =apply-guix-home= only after adding or removing a link. If it stops on a directory in the way (say, a real =~/.emacs.d=), move that directory aside and run it again.

Two links are made by hand:
#+begin_src shell
# Before the first `guix pull' on a new machine; Guix Home takes it over
mkdir -p ~/.config/guix
ln -sf  ~/dotfiles/guix-config/channels.scm  ~/.config/guix/channels.scm

# Made by stumpwm.d/bootstrap-quicklisp.sh
ln -sfnT ~/dotfiles/stumpwm.d/clx-truetype   ~/quicklisp/local-projects/clx-truetype
#+end_src
